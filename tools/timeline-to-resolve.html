DERUY 타임라인 → DaVinci Resolve 마커

서버의 plugins/DeruyPlugin/timeline/날짜.csv를 넣으면, 녹화 영상 위에 킬·수레 파괴·이벤트 시작 지점이 마커로 찍히는 파일(EDL)을 만들어요. 파일은 이 컴퓨터 밖으로 나가지 않아요.

1. 타임라인 CSV

여기에 CSV 파일을 끌어다 놓거나 눌러서 고르기

아직 파일이 없어요.

2. 녹화 정보

녹화와 서버 시계가 어긋나면 미세 조정으로 맞춰요. 킬 장면을 앞부분부터 보고 싶으면 "일찍 찍기"를 3~5초로.

3. 넣을 기록

4. 미리보기와 내보내기

CSV와 녹화 시작 시각을 넣으면 여기에 마커가 보여요.

  1. DaVinci Resolve에서 해당 타임라인을 열고
  2. 미디어 풀에서 타임라인 우클릭 → Timelines → Import → Timeline Markers from EDL...
  3. 받은 .edl 파일 선택
