# 서버 녹화 하이라이트 (Flashback 형식) — 계획

목표: 클라이언트 녹화 없이 서버가 전부 녹화하고, 싸움·이벤트 구간만 Flashback 리플레이로 남긴다.
참고: Paper Flashback / Flashback Server / SimplyFlashback / PMonitor (기능 참고만, 코드 복사 없음),
Flashback 1.21.11 소스는 파일 형식 확인용으로만 읽음(재배포 금지 라이선스).

## 요구사항 (Fsixel)
- 플레이어끼리 때리면 **때리기 1분 전부터** 싸움이 끝날 때까지 녹화 (싸움이 길어도 끊기지 않게)
- 이벤트(랜덤 이벤트·보물 수레 습격·KOTH·보급·드래곤 등)가 일어나면 이벤트 구간도 녹화
- 여러 개가 동시에 일어나도 각각 저장

## 설계
1. **패킷 수집**: 접속한 플레이어마다 서버가 보내는 패킷(인코딩된 바이트)을 Netty 파이프라인에서 복사
2. **되감기 버퍼**: 플레이어별로 최근 N분(기본 3분)을 메모리/임시 파일에 유지 — 30초마다 "스냅샷"(그 시점 화면 상태: 주변 청크·엔티티·탭 목록·플레이어 상태)을 찍어 그 지점부터 재생 가능하게
3. **트리거**
   - PvP 첫 타격: 두 사람 모두 "녹화 중"으로 전환, 시작점 = 타격 60초 전 이전의 가장 가까운 스냅샷
   - 전투 태그가 끝나면 +10초 뒤 저장 (도중에 다시 맞으면 계속 연장, 최대 길이 설정)
   - 이벤트: 시작~끝(+여유) 동안 이벤트 위치 근처 플레이어 녹화
   - 겹치면 같은 플레이어의 구간은 하나로 합침, 다른 플레이어는 각각 파일
4. **저장**: `plugins/DeruyPlugin/replays/<날짜>/<시각>_<종류>_<플레이어>.zip` (Flashback에서 바로 열림, 마커 포함)
5. **안전장치**: 설정으로 전체 끄기, 최대 동시 녹화 수, 디스크 상한(오래된 것부터 삭제), 녹화 사실 안내 메시지
