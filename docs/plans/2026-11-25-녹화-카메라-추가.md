# 서버 녹화 2차: 전투 태그·CCTV 카메라·킬캠·추적 카메라·편집 묶음 — 계획

요청(Fsixel, 2026-11-25): 제안한 것 중 수동 하이라이트 키·디스코드 알림·녹화 표시를 뺀 나머지 전부.

## 기능
1. **전투 태그 기준 녹화** — `replay.pvp.trigger: hit | combat-tag | both` (기본 both). 태그가 붙은 동안 + 꼬리, 태그 중 로그아웃도 그대로 저장
2. **고정 카메라(CCTV)** — `/camera add <이벤트> <이름> [반경]` 지금 서 있는 위치·방향 저장, 이벤트(koth·transport·randomevent·supply·dragon·always)가 열리면 사람이 없어도 녹화
   - `/camera list|remove|tp|test`, 한 이벤트에 여러 대(여러 각도)
   - 플레이어 없는 가상 시청자: 반경 안 청크·엔티티를 서버 상태로 직접 기록(매 틱 위치·데이터·장비·피격·사망, 블록 변화)
3. **킬캠** — 플레이어가 죽으면 죽은 사람·죽인 사람 시점으로 마지막 15초(+3초)만 따로 짧은 파일
4. **추적 카메라** — 하트 운송전 열차, 엔더 드래곤을 따라가는 카메라(움직이는 가상 시청자)
5. **편집용 묶음** — 저장할 때마다 같은 날짜 폴더에 리플레이별 Resolve 마커(.edl), 그날 타임라인 CSV 사본, index.csv(시각·종류·사람·길이·마커)
