# 추가 기능 계획 (2026-11-23)

요청: "추가하면 좋을 기능"에서 **KOTH 여러 명 점령(경합)만 빼고 전부**.
브랜치: `claude/plugin-features` (#3 `claude/plugin-improvements` 위에 쌓음 → 병합 순서 #1 → #2 → #3 → #4)

## 범위

| # | 기능 | 핵심 동작 |
|---|---|---|
| A | 수레 보물 흘림 | 손상 단계(75/50/25%)가 나빠질 때마다 남은 보물 일부를 바닥에 쏟음. 쏟은 만큼 최종 파괴 드롭이 줄어듦. 줍기 권한은 파괴 드롭과 같음 |
| B | 수레 움직임 연출 | 바퀴를 따로 띄워 이동 거리만큼 회전, 수레 몸체가 살짝 흔들림. 손상될수록 더 덜컹. 부서진 바퀴·빠진 바퀴는 단계별로 바뀜 |
| C | 랜덤 이벤트 보스바 | 추첨 중 / 진행 중 이벤트 이름 + 남은 시간. 끝나면 사라짐. 중간 접속자도 보임 |
| D | `/deruy status` | KOTH·슈퍼KOTH·바운티·보급·슈퍼보급·랜덤 이벤트·수송·질문타임·빙고·라이프스틸·로케이터바 상태 한 화면 |
| E | 영상 편집용 타임라인 | 킬, 하트 변화, 이벤트 시작·끝, KOTH 점령, 바운티 처치, 보급, 수송 손상·파괴·도착을 `timeline/YYYY-MM-DD.csv`에 시각(초 단위)과 함께 기록. `/deruy timeline` 으로 파일 위치·건수 확인 |

범위 밖: KOTH 경합, 버그 목록(별도 승인 대기), 처치 아이템 몹 발동 여부(질문 대기).

## 설계 메모

- **A**: `TransportRaid` 가 실행마다 `remaining` 복사본을 들고, 단계 악화 시 `spill-per-stage`(기본 0.15) 비율만큼 무작위로 꺼내 `TransportLoot.burst(..., quiet)` 로 작게 쏟음. 설정 원본(`singles`)은 건드리지 않음.
- **B**: 리소스팩에 몸체(바퀴 없음) 4단계 + 바퀴 3종(멀쩡·살 하나 빠짐·많이 부서짐) 모델. `transport-model.yml` 파트에 `spin: true`, 단계별 `parts:` 덮어쓰기(`none` = 숨김). 이동 거리 / 바퀴 반지름(0.5) = 회전각. 흔들림은 단계별 진폭.
- **C**: `RandomEventManager` 안 BossBar. 1초마다 갱신. `random-events.bossbar: true`.
- **D**: `plugin.yml` 에 `deruy` 명령 + `deruy.admin` 권한. 기존 getter 만 사용.
- **E**: `HeartAuditLog` 처럼 별도 스레드 순서 쓰기. CSV(UTF-8 BOM, 엑셀에서 한글 안 깨지게). `timeline.enabled: true`.
